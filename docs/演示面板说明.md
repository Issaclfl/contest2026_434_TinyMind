# 演示面板（TinyMind Panel）

**它解决的问题**：这条链路的"界面"原本是板子的串口控制台和 PC 上的模拟器终端——
评审看着像调试现场，不像产品。这个面板把**运行过程**和**控制**放进一个网页：

```
浏览器（面板）  板子（黄山派）        网关（ESP32-S3）        被控设备（米家）
   │  http://127.0.0.1:8080              │                      │
   ├── GET  /status ────────────────────►│  模型 / Wi-Fi / PPP   │
   │                                      │  最近一次问句（含板子问的）
   ├── POST /v1/chat/completions ───────►│  本地分类器 → miIO ──►│◄── get_prop
   │        （model="cmd"，与板子同一条路）│                      │    （直连读状态）
```

三件事因此第一次能同屏：

1. **网关状态**：本地模型、Wi-Fi、PPP 会话、板子是否在线、最近路由、上次问句——读网关
   自己的 `/status`（那几行是网关注册的 status provider 输出的，是同一个事实来源）。
2. **设备卡片**：被控设备**真实状态**由面板每次直连设备读回（用官方 `miio.protocol`
   模块组包），**不是面板自己记的账**。设备状态栏里的"读取时间"就是刚才那次读取。
3. **事件流**：谁问的（面板 / 板子）、问了什么、网关答了什么、**设备状态怎么变**
   （例如 `台灯: 色温 4000→2700`）。

## 怎么跑

```bash
# 0) 被控端：官方模拟器（PC 上）
miiocli devtools miio-simulator --file pc_side/yeelight_lamp.yaml

# 1) 面板（PC 上，需要能访问网关）
python pc_side/tinymind_panel.py --gateway 10.138.138.122
#   浏览器打开  http://127.0.0.1:8080

# 可选：设备表从 S3 的 sdkconfig 读（只读名称/型号/IP，token 不回显）
python pc_side/tinymind_panel.py --gateway 10.138.138.122 \
       --sdkconfig /path/to/esp32s3_gateway/sdkconfig
```

| 选项 | 说明 |
|---|---|
| `--gateway` | S3 网关的 IP（板子经 PPP 看到的 10.0.0.1 是网关的**另一侧**地址，面板要用 WiFi 侧） |
| `--https` | 用 TLS 访问网关。默认走 http：:443 是同一台 httpd 的 TLS 监听，**本板实测会周期性拒绝新连接**（见下），面板不需要担这个风险 |
| `--miio-ip` / `--token` | 被控设备地址与凭据。默认 `127.0.0.1` + 官方模拟器的**固定全零 token**（公开常量，不是凭据） |

## 实测记录（2026-09-20）

**数据契约**（页面读的每个字段都在真实响应里）：

```
契约检查: 全部通过
  [panel] 15:25:52 关闭空调 -> 空调已关闭 | 台灯: 开→关（空调 与它共用同一个模拟器实例，状态同步变化）
  [panel] 15:25:52 打开台灯 -> 台灯已打开 | 台灯: 关→开（…）
  卡片 台灯: [{'label': '开关', 'value': 'off'}, {'label': '亮度', 'value': 80}, {'label': '色温', 'value': 4000}]
  卡片 空调: [{'label': '开关', 'value': 'off'}]  共用说明: 台灯
```

**一次完整往返**（说中文 → 网关本地判断 → 设备真的变）：

```
POST /api/say {"text":"台灯调到百分之五十"}  -> 台灯亮度已调到 50   (158 ms)
设备状态读回                                    bright: 50 → 50 ✔ 与指令一致
```

`GET /status` 里同时能看到**板子自己发的**问句（`asked : "..."`）与
`board : PPP session up (10.0.0.2)`——所以演示里"板子问的那一句"也会出现在面板上
（答复在板子的屏与喇叭上）。

## 如实标注的边界

- 面板的"控制"按钮走的是**和板子完全同一条离线路径**（网关上的本地分类器 → 局域网
  miIO），不是另开一条捷径；但它**不经过板子**，所以按面板的按钮时板子的屏与喇叭不参与。
- 两台"设备"共用同一个官方模拟器实例（官方模拟器端口写死 54321，一台主机只能起一个），
  面板会在卡片上写明"与 XX 共用同一个模拟器实例"，事件流里也只报一次变化——
  这是**如实呈现**，不是把两台设备演成两台真机。
- 面板自己不做意图判定：判定在网关上（`model="cmd"`）。面板只负责显示与转发。
- 面板显示的是被控设备的真实状态，但被控设备本身是**官方模拟器**（协议真实、设备模拟）。
- 渲染验证方式：本机当时没有可用的无头浏览器，因此**逐项验证的是**内联 JS 语法
  （`node --check`）、页面结构与 API 数据契约；**没有做像素级的视觉验收**。
